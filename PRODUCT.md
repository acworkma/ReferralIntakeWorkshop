# Product context

Referral Intake Reference is an operator-facing demonstration of a secure, event-driven referral workflow on Azure. A document arriving in a storage account starts the workflow on its own; reviewers observe dual-engine extraction, inspect disagreements, and approve or return the result. It must never imply suitability for real records without further threat modeling, compliance review, and production hardening.

The primary task is rapid, accountable human review. Public-workspace safety, traceability, accessible interaction, and a clear, enforced boundary between the test-only mock identity fixture and Azure Microsoft Entra ID are non-negotiable.
