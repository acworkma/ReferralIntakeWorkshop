# Design system

The interface uses an operations-led “control ledger” vocabulary: dense but calm rows, ruled work surfaces, strong state labels, and a blue-violet action color. It avoids dashboard tiles in favor of a continuous queue and a side-by-side evidence workspace.

- Typography: system UI stack; fixed scale; tabular numerals for measurements.
- Surfaces: `--canvas`, `--panel`, and `--raised`; 1px rules establish hierarchy.
- Accent: `--action` only for selection, focus, and primary action.
- Radius: 4–12px based on control scale; no ornamental pills.
- Motion: 180ms transitions; progress communicates processing state; reduced-motion respected.
- Themes: complete light and dark tokens, selected by light/dark/system preference.
- Breakpoints: two-column review collapses below 920px; navigation labels collapse below 680px.
